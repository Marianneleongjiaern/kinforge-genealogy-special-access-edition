## Public and Special Access connection

The public KinForge website and the Special Access Edition website should stay connected but separate:

- The public site is the open customer-facing site with product information, plans, downloads, support, tutorials, About Us, Mission, Vision, Values, legal pages, and the prompt for users who already have a Special Access code.
- The Special Access Edition site keeps its own UI, UX, workflow, rules, downloads, tutorials, and code-first access gate.
- Users with a Special Access code should move from the public site to this Special Access site, then enter the private code here before seeing the protected edition workflow.
- The Special Access site may link back to the public site for support, public documentation, legal context, and general KinForge information, but it should not replace the public site or reuse the public account-first landing flow.
